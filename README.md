## 3. Learn Statistical Foundations
* **Descriptive Statistics:** Mean, Median, Mode, Variance, Standard Deviation, and Percentiles.

## 4. Understand Data Types & Structures
* **Numerical Data:** Continuous and Discrete.
* **Categorical & Ordinal Data:** Nominal categories and ordered sequences.

## 5. Follow Data Science Best Practices
* Clean coding standards (PEP 8), meaningful naming, documentation, reproducibility, and responsible analysis.
